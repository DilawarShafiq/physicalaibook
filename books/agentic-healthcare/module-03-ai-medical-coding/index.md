# Module 3: AI Medical Coding & CDI

*ICD-10, CPT & Clinical Documentation Intelligence*

**Duration:** 6 hours · **Level:** Advanced · **Lessons:** 3

Medical coding is the translation of clinical documentation into billable codes. AI achieves 95%+ accuracy on high-volume, well-documented encounters. Build coding agents that never miss a secondary diagnosis or a modifier.

## Prerequisites

- [Module 2: Eligibility & Prior Auth Agents](../module-02-eligibility-prior-auth-agents/index.md)

:::info Learning outcomes

By the end of this module you will be able to:

- Build an AI coding agent using LLM-based diagnosis and procedure code extraction
- Implement CDI query generation for underdocumented encounters
- Deploy a coding accuracy validation pipeline against a human coder benchmark
:::

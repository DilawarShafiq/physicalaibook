# Module 6: Dexterous Manipulation

*22-DOF Hands, Tactile Sensing & Grasp Planning*

**Duration:** 7 hours · **Level:** Advanced · **Lessons:** 3

G1's 22-DOF hands must thread a needle, pick up an egg, and handle medication. Build the complete manipulation stack from hand design to learned in-hand policies.

## Prerequisites

- [Module 5: Foundation Models & VLA Architecture](../module-05-foundation-models-vla/index.md)

:::info Learning outcomes

By the end of this module you will be able to:

- Specify a 22-DOF robotic hand for healthcare manipulation
- Implement tactile-guided grasping and in-hand manipulation
- Design bimanual coordination policies for complex tasks
:::

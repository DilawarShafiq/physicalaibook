# Module 2: Eligibility & Prior Auth Agents

*Automating the Front Door of the Revenue Cycle*

**Duration:** 6 hours · **Level:** Intermediate · **Lessons:** 3

Insurance verification and prior authorization are the highest-volume, most automatable tasks in healthcare admin. Build agents that eliminate phone calls, faxes, and manual portal entry.

## Prerequisites

- [Module 1: The US Healthcare Admin Crisis](../module-01-us-healthcare-admin-crisis/index.md)

## Learning Outcomes

By the end of this module you will be able to:

- Build a real-time eligibility verification agent using HIPAA 270/271 EDI
- Design a prior authorization submission and follow-up agent
- Implement multi-payer support with graceful fallback to portal scraping

# Module 6: HIPAA-Compliant AI Agent Deployment

*Architecture, BAAs, Audit Trails & Production Safety*

**Duration:** 5 hours · **Level:** Advanced · **Lessons:** 3

Every AI agent that touches PHI in US healthcare must be HIPAA-compliant. This is not optional and it is not just a policy — it is architecture. Build it right from day one.

## Prerequisites

- [Module 5: The Personal Medical Biller](../module-05-personal-medical-biller/index.md)

:::info Learning outcomes

By the end of this module you will be able to:

- Design a HIPAA-compliant AI agent infrastructure with complete audit trails
- Implement BAA-compliant vendor chain for all AI and cloud services
- Build PHI detection and masking for agent logs and model inputs
:::

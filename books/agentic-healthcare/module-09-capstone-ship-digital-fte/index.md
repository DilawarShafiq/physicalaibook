# Module 9: Capstone: Ship a Digital FTE

*From Zero to a Running Eligibility Agent*

**Duration:** 5 hours · **Level:** Advanced · **Lessons:** 3

Turn the book into a deployed agent: scope a Digital FTE, build an eligibility agent end to end with Claude and real payer transactions, and take it to production safely.

## Prerequisites

- [Module 2: Eligibility & Prior Auth Agents](../module-02-eligibility-prior-auth-agents/index.md)
- [Module 6: HIPAA-Compliant AI Agent Deployment](../module-06-hipaa-compliant-ai-deployment/index.md)

:::info Learning outcomes

By the end of this module you will be able to:

- Scope a Digital FTE with a clear role, tools, and escalation rules
- Build an eligibility agent end to end with Claude tool use and real EDI/FHIR transactions
- Take a healthcare agent to production with a HIPAA and go-live checklist
:::

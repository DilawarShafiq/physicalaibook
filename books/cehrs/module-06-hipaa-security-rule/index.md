# Module 6: HIPAA Security Rule & Access Control

*Safeguards, Breach Notification & Audit Management*

**Duration:** 5 hours · **Level:** Intermediate · **Lessons:** 3

Where the Privacy Rule governs who sees PHI, the Security Rule governs how electronic PHI (ePHI) is protected. Know all three safeguard categories, breach notification timelines, and how to respond to a security incident.

## Prerequisites

- [Module 5: HIPAA Privacy Rule](../module-05-hipaa-privacy-rule/index.md)

:::info Learning outcomes

By the end of this module you will be able to:

- Apply all three HIPAA Security Rule safeguard categories
- Implement role-based access control and audit monitoring
- Execute the breach notification process within required timelines
:::
